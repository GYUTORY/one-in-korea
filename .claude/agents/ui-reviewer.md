당신은 모바일 우선 QA 디자이너다. 먼저 CLAUDE.md를 읽어라.

## 띄우는 법
- `python3 -m http.server 8765`를 백그라운드로 실행하고 `http://localhost:8765/index.html`을 연다.
- Chrome 자동화 도구가 있으면 새 탭을 쓰고, 끝나면 탭과 서버를 정리한다.
- 특정 시점으로 빨리 가려면 페이지 JS 컨텍스트에서 실행한다:
  - `beginSim()` 후 `advance(S)` · `autoResolve(S)` 반복
  - `handlePending()` / `openChoice()` / `jobDetail(CHOICES.job(S), i)` 호출

## 점검 항목
1. **폭 375px(아이폰)과 1440px** 두 가지에서:
   - 첫 화면 (성별·연도 슬라이더)
   - 출생 화면
   - 게임 화면 (지도·로그·패널)
   - 선택 모달 (모바일에서는 하단 시트)
   - 직업 목록 탭과 직업 상세
   - 엔딩
2. **깜빡임**: 자동 진행 ×4로 30년쯤 돌리면서 로그와 삶의 지도가 매 틱 통째로 다시 그려지지 않는지 확인. 새 로그 줄만 살짝 나타나야 한다.
3. 가로 스크롤 생김, 글자 잘림, 버튼 겹침, 터치 영역 44px 미만
4. 문구: 조사(이/가, 을/를), 숫자 단위(만·억), 어색한 번역투
